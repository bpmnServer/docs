    BPMN-Server Designer FAQ#

    A curated list of frequently asked questions for BPMN designers working with the bpmn-server engine.

    1. How do I trigger a process from code?#

    You can trigger a process from your code by invoking the process through an API. Here is an example of how you can do this:

        const api = new BPMNAPI(new BPMNServer(configuration,new Logger({ toConsole: false}),{cron:false}));
let response=await api.engine.start('Leave Request',{type:'Vacation'},SystemUser);

let instanceId=response.instance.id;

console.log('Invoking Buy');

response = await api.engine.invoke({instanceId , elementId: 'task_Buy' },
    { model: 'Thunderbird', needsRepairs: false, needsCleaning: false },SystemUser);

    In this code, the BPMNAPI is used to start a process and then invoke a task within that process. The SystemUser is used to define the user that is invoking the process and task. In real applications, you would get the userName and userGroups from your application's User Access [Reference: "./docs\invokation.md##-invoking-workflow-scenarios-##-invoking-proccess-through-api"].

    2. How can I assign tasks to specific users or roles?#

    Use a userTask with an assignee from process data:

    <bpmn:userTask id="task1" name="Review">
  <bpmn:extensionElements>
    <camunda:assignee>\${data.reviewer}</camunda:assignee>
  </bpmn:extensionElements>
</bpmn:userTask>

    3. How do I implement parallel approvals (multi-instance)?#

    Use multiInstanceLoopCharacteristics:

    <bpmn:userTask id="approveTask" name="Department Approval">
  <bpmn:multiInstanceLoopCharacteristics isSequential="false">
    <bpmn:loopCardinality>data.departments.length</bpmn:loopCardinality>
  </bpmn:multiInstanceLoopCharacteristics>
</bpmn:userTask>

    4. Can I call a subprocess or reusable workflow?#

    Yes, with a callActivity:

    <bpmn:callActivity calledElement="subProcessId" />

    5. How do I raise an error or escalation from a script task?#

    Use these methods inside a service or script:

    this.raiseError('validationFailed', 'Data is invalid');
this.raiseEscalation('NotifyAdmin', { user: 'admin' });

    6. Can I persist data or log custom metadata?#

    Yes:

    this.saveData({ step: 'approved' });
this.logger.log('Custom note');

    7. How can I run BPMN tests or simulate scenarios?#

    Use test automation:

    engine.start('TestProcess').then(instance => {
  assert(instance.data.result === 'OK');
});

    8. How do I handle timeouts or delays?#

    Use a Timer Event:

    <bpmn:intermediateCatchEvent id="wait1">
  <bpmn:timerEventDefinition>
    <bpmn:timeDuration>PT30S</bpmn:timeDuration>
  </bpmn:timerEventDefinition>
</bpmn:intermediateCatchEvent>

    9. What happens if the server crashes or restarts?#

    • Processes auto-resume from the database
    • Engine supports fail-safe recovery

    10. Can I define custom service tasks (API, DB, Email)?#

    Yes:

    engine.executeServiceTask = async (task, context) => {
  if (task.name === 'SendEmail') {
    await EmailService.send(context.data);
  }
};

    11. Is versioning supported?#

    Yes, you can deploy and run multiple versions of a process.

    12. How do I trace or debug a process?#

    Enable logging or use:

    engine.trace(instanceId);

    Also enable logLevel: debug in the engine configuration.

    13. Can I pause/resume a process manually?#

    Yes, processes pause at wait states. Resume via:

    engine.invoke(instanceId, { approved: true });
